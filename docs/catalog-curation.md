# Catalog admission while Big 6 launching is validated

The current 24-entry catalog contains the 17 original Big 6 examples and only enough Paramount+/Peacock fixtures to exercise movie and series routes. Max is retired from V1. Broad catalog expansion is paused until physical launch results arrive.

Keep discovery/availability separate from launching. Match exact title/year/edition and attach an independently checked provider destination. A trailer, homepage, generic search page, or different adaptation is not an exact-title mapping. Record URL/date/identity evidence in the launch registry without guessing opaque IDs or schemes.

Before any later addition, distinguish base subscription from rent/buy/add-on access and retain region/freshness/provenance. Current fixture offers are illustrative. Content annotations and each promotional asset need separate review: a safe title can have unsafe art. Neutral local art is the fallback for unreviewed promotions.

Admission happens before content filters. Every selected-provider offer must independently resolve an exact title; one provider's link cannot admit another provider's offer. All surfaces and Watch actions use this rule. Unknown/unlinked metadata can exist in a future raw source, but cannot create a homepage Watch action.

Run tests, production build, browser checks, and regenerate original SVGs with `npm run artwork` when fixtures change. Preserve source identifiers and artwork generation sources. No catalog import or API integration is started by this milestone.
